## MCP findings (→ v0.2.0 backlog, filed in tasks.md)

- **`summarise_calibration` is GLM-only.** It looks for `<case>.par` (a GLM
  artifact); pestpp-ies writes `<case>.<iter>.par.csv`, `<case>.<iter>.obs.csv`,
  `<case>.rei`, `<case>.phi.actual.csv` — none satisfies the tool, so
  summarising an IES run fails. 7e-B1.x added `.iobj` parsing for GLM; IES
  needs the equivalent (phi already parses via `_pestpp_progress` — the summary
  step should too).
- **No MCP tool can switch NPF `k` from an inline array to an external
  `OPEN/CLOSE` file** — required for calibration templating when K was assigned
  via zones; the agent restored one shipped nam line instead.
- **~2M-cell K arrays cannot be passed inline** to `add_npf_package` (payload
  limit) — `assign_k_from_zones` from a zone-polygon shapefile is the working
  path (values verified identical to the shipped procedure).
