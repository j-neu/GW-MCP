# CSUB support and the 6d CSUB validation target — Design

**Date:** 2026-09-19
**Status:** Approved (owner) — ready for implementation plan
**Scope:** v0.3.0 capability (CSUB is not in the v0.1.0 release scope; see `TASKS.md` § 7d v0.3.0 gate)

---

## Goal

Add MODFLOW 6 **CSUB** (subsidence) capability to groundwater-mcp and validate it
closed-book on the `1DSubsidenceModeling-MF6CSUB` Tier-1 holdout target, so that
target can pass the 6d rerun-improvement loop and gate the v0.3.0 release.

Three capabilities are added:

1. Build a CSUB model (`add_csub_package`).
2. Observe and post-process subsidence (CSUB observation records, compaction
   reader, subsidence plot).
3. Calibrate CSUB interbed properties through the automated calibration chain
   (`setup_calibration` gains CSUB and k33 parameter targets, plus a derived
   time-series observation source).

### The target

`github.com/leila-saberi/1DSubsidenceModeling-MF6CSUB`, branch `Multi-IB`, 48
California Central Valley sites, staged 2026-09-19 at
`D:\Claude Projects\GW-MCP-holdout\selected\1DSubsidenceModeling-MF6CSUB\`
(~217 MB; the D: root is the permission allow-listed holdout). Each site
directory holds `prep_data.py`, `source_data/` (lithology, observation,

Per-site model (from `model_functions.py`):

- **Grid**: DIS, `nlay` (2–5) × 1 row × 1 col, `delr = delc = 1.0`,
  `LENGTH_UNITS FEET`, `TIME_UNITS DAYS`.
- **Time**: many stress periods (historic + predictive), `perioddata` derived
  from observation dates; period 0 steady, the rest transient.
- **Packages**: IC, NPF (`icelltype=1`, per-layer `k`, `k33`), STO
  (`iconvert=0`, `ss=0`, `sy=0`), time-varying **GHB** (one record per layer
  per period, `cond=50000`), **CSUB6**, a head OBS and a CSUB OBS.
- **CSUB6 options used**: `head_based=False`,
  `initial_preconsolidation_head=True`,
  `specified_initial_interbed_state=True`,
  `update_material_properties=False`, `ndelaycells=19`, `beta=2.2270e-8`,
  `gammaw=62.48`, `ninterbeds`, per-layer `sgm`/`sgs`, per-layer `cg_theta`,
  `cg_ske_cr`; `packagedata` records of
  `[icsubno, cellid, cdelay, pcs0, thick_frac, rnb, ssv_cc, sse_cr, theta, kv, h0]`;
  filerecords for `zdisplacement`, package convergence and `strainib`.
- **CSUB observations**: `compaction-cell`, `preconstress-cell`,
  `elastic-compaction-cell`, `inelastic-compaction-cell`,
  `interbed-compaction-pct` (per interbed), `delay-preconstress` / `delay-head`
  (per interbed, selected delay cells).
- **Calibration** (`ies_functions.setup_pst`): pestpp-ies via pyemu `PstFrom`.
  Adjustable families: GHB heads (primary, additive per datetime/per layer with
  temporal correlation), CSUB `packagedata` columns
  (`pcs0`/`thick_frac`/`rnb`/`ssv_cc`/`sse_cr`/`theta`/`kv`/`h0`), per-layer
  `cg_theta` / `cg_ske_cr`, and per-layer `k33`. Observations: head, per-layer
  compaction, total subsidence, interbed strain, derived difference/percentage
  series. The repo's own `__main__` example uses `H201`.

### Current MCP gaps (verified in source)

- No CSUB package, observation, post-processing or metadata code anywhere
  (`grep -i csub src tests` is empty).
- `setup_calibration` is hard-wired to `_SUPPORTED_TARGETS = ("npf:k",)`
  (`calibration.py:1005`), with an NPF-k-specific snapshot/rewire/normaliser
  stack (`_restore_or_snapshot_k_base`, `_impl_rewire_npf_k_external`,
  `_normalise_parameterisation` and the zone/multiplier variants).
- `_impl_generate_ins_from_obs_csv` targets the **first data row** of the model
  obs CSV — a steady-state assumption. The CSUB target's observations are a
  time series, so a new observation-interface shape is required.
- `_impl_add_boundary_package` has no external stress-period-data file form;
  the mf6brabant rerun-3 note claims one was used, so this must be re-verified.
- Tool-count guard is a single literal `_EXPECTED_TOOL_COUNT = 70`
  (`tests/test_mcp_protocol.py:61`) plus a per-module `_EXPECTED_TOOLS` map.

### Owner scoping decisions

- Full scope: **build + observe + calibrate**.
- Calibration bar: **CSUB interbed properties + k33**; GHB heads fixed to the
  repo's processed field levels. GHB-head temporal parameterisation is
  explicitly deferred (recorded as backlog).
- Architecture: **generalise `setup_calibration` with target resolvers**
  (approach A), not a second `PstFrom`-based interface builder.

## Design overview

Four components, implemented in order. Components 1–2 are prerequisites for the
closed-book build/observe journey; component 3 adds the calibration bar;
component 4 validates.

```
prep_data.py ──► processed_data CSVs ──┐
source_data CSVs ──────────────────────┤
                                        ▼
                          MCP tools (closed-book agent)
   add_csub_package ──► CSUB6 + obs ──► run ──► read_compaction / plot_subsidence
        │                                              │
        └──────────► setup_calibration(targets) ◄──────┘
                     pestpp-ies ──► summarise_calibration
```

### Component 1 — `add_csub_package` (builder.py, +1 tool)

Wrap `flopy.mf6.ModflowGwfcsub` following the `add_sto_package` pattern
(`_impl_add_csub_package`, meta write, `save_sim`, `register(mcp)`).

Signature (all field arguments 0-based where they are cell/interbed indices):

```python
def add_csub_package(
    model: str,
    packagedata: list | dict,          # interpolatable records, or {"filename": ...}
    ninterbeds: int | None = None,     # default: len(packagedata)
    sgm: float | list | None = None,   # per-layer arrays
    sgs: float | list | None = None,
    cg_theta: float | list | None = None,
    cg_ske_cr: float | list | None = None,
    head_based: bool = False,
    initial_preconsolidation_head: bool = False,
    specified_initial_interbed_state: bool = False,
    update_material_properties: bool = False,
    ndelaycells: int | None = None,
    beta: float | None = None,
    gammaw: float | None = None,
    interbeddata: list | None = None,
    stress_period_data: dict | None = None,
    observations: dict | None = None,   # {csv_name: [(name, obs_type, index), ...]}
    filerecords: dict | None = None,    # zdisplacement / package_convergence / strainib / compaction
    print_input: bool = True,
    save_flows: bool = True,
    pname: str | None = None,
) -> dict
```

Behaviour and invariants:

- Reuse the `add_boundary_package` replacement/pname logic
  (`_packages_of_type` + `_pkg_nam_name`) so re-adding replaces only the named
  package.
- Validate: `ninterbeds == len(packagedata)` when both given; each record has
  11 fields; `icsubno` contiguous from 0; every cellid resolves on DIS/DISV/DISU
  via the `utils.grid` resolvers; `cdelay` is `"delay"`/`"nodelay"`; per-layer
  array lengths match `nlay` (`grid_size`); `ndelaycells` positive when any
  delay interbed is present.
- Convert 0-based cellids to flopy/MF6 form, matching existing builder tools.
- Persist a `csub` block to `.gwmcp_meta.json`: `ninterbeds`, `ndelaycells`,
  `interbeds` (icsubno → layer, cdelay), `filerecords`, and the observation
  registration.
- Write external packagedata when `packagedata` is given as
  `{"filename": ...}` (needed for calibration templating; see Component 3).
- `written: false` deferred write; `next_steps` attaches automatically;
  adopted model raises `MODEL_ADOPTED_READONLY` via `save_sim`.
- Result: `{model, package: "CSUB", ninterbeds, n_delay_interbeds, layers,
  filerecords, written, warning?}`.

### Component 2 — CSUB observations and post-processing (+3 tools)

**Observations** are written as part of `add_csub_package` via the `observations`
argument, because MF6 attaches CSUB observations to the CSUB package
(`csub.obs.initialize(...)`, `ModflowUtlobs`). The accepted `obs_type` values
mirror the package spec: `compaction-cell`, `preconstress-cell`,
`elastic-compaction-cell`, `inelastic-compaction-cell`,
`interbed-compaction-pct`, `delay-preconstress`, `delay-head`. Cell-typed
records take a cellid; interbed-typed records take an interbed number (and a
delay-cell index for the delay types).

**`read_compaction(model)`** (+1 tool):

- Reads `<gwf>.csub.obs.csv` (name from the CSUB obs registration / OC-declared
  output) and, when present, `<gwf>.strainib.csv`.
- Returns per-time compaction per layer, the derived cumulative subsidence
  (sum of the `compaction-cell` columns), and interbed strain/percent
  compaction. Values capped by `max_rows` with a full table written to a
  workspace CSV, following the `read_budget`/`summarise_calibration` overflow
  pattern.
- Behaviour on a model with no CSUB obs fails loudly
  (`OUTPUT_FILE_MISSING`), consistent with 7e-B2.

**`plot_subsidence(model, observed_csv=None, ...)`** (+1 tool):

- Time series of simulated cumulative subsidence, optionally overlaid with
  observed subsidence from a CSV (`time` + value columns, auto-detecting the
  repo's `Subsidence_ft`).
- Returns the PNG natively as `ImageContent` plus the file path, following
  `plot_heads_map` (`postprocess.py:1384`).

**Derived time-series observations** (+1 tool, calibration substrate):

`import_subsidence_observations(model, observed_csv, time_col, value_col,
sim_source)` registers a time-series observation target:

- Observed values/dates from the CSV, stored under a new `derived_observations`
  meta key (parallel to the existing `observations` block).
- The simulated value is derived at run time: `sim_source` names the model's
  compaction columns to sum (default: all `compaction-cell` columns of the CSUB
  obs CSV) and the time column to match on.
- The derivation is injected into the generated forward wrapper (the existing
  `_generate_forward_wrapper` mechanism) so the model output contains a
  ready-to-read derived series; this reuses, rather than bypasses, the
  forward-wrapper path.

### Component 3 — calibration parameter targets (+0 tools)

Generalise `setup_calibration` with a target resolver registry. The
`parameterisation` spec keeps its current shape (`{key: {target, scope, ...}}`);
`_SUPPORTED_TARGETS` is replaced by a registry of resolvers.

New targets:

| Target | Scope | Parameter | Rewire / template |
|---|---|---|---|
| `npf:k33` | `all` / `layer` / `cells` | per cell | mirror the NPF `k` rewire on `npf.k33` |
| `csub:packagedata` | `columns` (+ optional `layer`/`interbeds`) | per (column × interbed) | CSUB `packagedata` written external, wide-token template over the selected numeric columns |
| `csub:cg_theta` | `layer` | per layer | per-layer external array, one template per layer |
| `csub:cg_ske_cr` | `layer` | per layer | per-layer external array, one template per layer |

Invariants preserved from the existing path:

- One call emits the whole interface: `.pst`, template(s), instruction file,
  external targets, parameter table.
- Wide fixed-width tokens (`_TPL_TOKEN_WIDTH`), `derinclb > 0` on every group,
  safe default bounds (`initial × lower_factor` / `× upper_factor`).
- `csub:packagedata` bounds default to value × 0.05 / × 20 for the CSUB
  columns, matching the repo's own priors, with `partrans` defaulting to `none`
  for `rnb`/`thick_frac` and `log` where positive-only.
- Multi-target specs (e.g. `csub:packagedata` + `csub:cg_ske_cr` + `npf:k33`)
  assemble into one `.pst`.
- Zones/multiplier scopes stay `npf:k`-only in this iteration.

The observation interface for CSUB calibration uses the derived time-series
targets from Component 2; `obs_source` gains a `"derived"` mode that builds the
instruction file from the derived series rather than the first row of the head
obs CSV. The existing `"model"` (steady-state, first-row) mode is unchanged.

## Data flow

1. Agent runs `prep_data.py` per site → `processed_data/{site}.model_property_data.csv`
   (per-layer lithology/K/CSUB properties) and `{site}.ts_data.csv` (dated
   groundwater levels).
2. Agent derives, in ordinary Python, the TDIS period table, the per-layer GHB
   head series, the interbed `packagedata` records, and the CSUB obs list.
3. `create_model` → `set_simulation` → `add_dis_package` → `add_npf_package` →
   `add_ic_package` → `add_sto_package` → `add_boundary_package(GHB)` →
   `add_csub_package` (with obs + filerecords) → `add_oc_package` → `check_model`
   → `run_simulation`.
4. `read_compaction` / `plot_subsidence` for post-processing; `compare` against
   the shipped `{site}_sub_data.csv`.
5. `setup_calibration` with the CSUB/k33 targets and `obs_source="derived"` →
   `run_pestpp_ies` (or `start_calibration`) → `summarise_calibration`.

## Error handling

New error paths reuse the existing envelope (`_err(code, message, suggestion)`):

- `INVALID_INPUT` — packagedata/ninterbeds mismatch, bad `cdelay`, unknown
  obs_type, out-of-range interbed or cellid, `ndelaycells` missing with delay
  interbeds, per-layer array length mismatch.
- `PACKAGE_MISSING` — CSUB calibration target requested with no CSUB package,
  or no `k33` on NPF.
- `OUTPUT_FILE_MISSING` — `read_compaction` / `plot_subsidence` with no CSUB
  obs output, or a calibration run that died before writing results.
- `MODEL_ADOPTED_READONLY` — any CSUB builder/labelling call on an adopted
  read-only model.
- `PAYLOAD_TOO_LARGE` — inline packagedata beyond a documented cap
  (file form required), mirroring the DISV inline guard.

Fail-loudly rules: a CSUB unpackagedata field that cannot be resolved, a
negative/non-finite CSUB property that is physically invalid (`thick_frac` ≤ 0,
`rnb` < 1, `theta` outside (0,1)), and a derived observation with no matching
simulated column all error rather than silently writing a wrong model.

## Testing strategy

Following the existing layers:

- `tests/test_csub.py` — unit + integration: build the tiniest CSUB column
  (1×1, 2 layers, no-delay interbeds), assert meta, deferred write, parameter
  validation errors, and `read_compaction` round-trip against a synthetic CSUB
  obs CSV. MF6-gated build→run→read test using the `requires_mf6` pattern.
- `tests/test_csub_obs.py` (or folded into `test_csub.py`) — observation
  records, derived-series registration, `plot_subsidence` PNG.
- `tests/test_csub_calibration.py` — target normalisers, packagedata
  externalisation + template round-trip, multi-target `.pst` assembly,
  derived-observation instruction file, and a binary-gated tiny pestpp-ies run.
- `tests/test_mcp_protocol.py` — bump `_EXPECTED_TOOL_COUNT` and the
  `_EXPECTED_TOOLS` lists as each tool lands.
- Same-commit doc updates: `README.md`, `tools.md`, `architecture.md`,
  `research/capability-matrix.md` (CSUB moves from "extra scope" to a covered
  row), `TASKS.md`.

## Risks and open items (to de-risk in the plan's first tasks)

1. **Externalising CSUB `packagedata` for templating.** FloPy list-package
   data externalisation (`set_data({"filename", "data"})` vs
   `set_all_data_external`) is not yet used anywhere in the MCP for list/table
   data. A spike must prove: write packagedata external → template a column →
   pestpp-ies substitutes → MF6 reads it.
2. **Time-series instruction file.** The first-row pif assumption is
   steady-state; the derived-series pif must read the correct rows/columns of a
   time-indexed CSV. Spike it before wiring into `setup_calibration`.
3. **`add_boundary_package` external SPD form.** The mf6brabant rerun-3 note
   claims `{"filename": ...}` was used, but the current code has no such branch.
   Verify; if absent, GHB for hundreds of periods still fits inline (1×1×nlay)
   but the discrepancy must be recorded.
4. **CSUB obs CSV naming.** MF6/flopy may rename the `compaction` obs columns
   (uppercasing, truncation at 12 chars). Column matching must be
   case-insensitive and prefix-aware, as the head OBS path already is.
5. **Wrapper scope.** CSUB parameter templates need no multiplier wrapper, but
   the derived-subsidence step does need the generated forward wrapper
   (stdlib-only, space-free) to survive the Windows/pestpp constraints already
   documented.

## Addendum (2026-09-19) — final-review fixes

The whole-branch review of the delivered capability found two Critical gaps that
would make the closed-book Target 9 run fail, plus three Important defects. The
owner approved extending this spec rather than dispatching with known blockers.

**Critical 1 — derived-observation time axis.** `set_simulation` exposes no
`start_date_time`, so `time_units="DAYS"` produces a TDIS with no start date and
the CSUB obs CSV `time` column is *elapsed* model time while the holdout
observations are calendar dates (the holdout itself converts elapsed days with
`start_date_time + Timedelta(days=i)`). The matcher must therefore convert
elapsed times to dates before comparing, and must never interpret an elapsed
number as a year.

- `set_simulation` gains an optional `start_date_time` (ISO-8601 date or
  datetime string), applied to `ModflowTdis` and persisted in metadata.
- `setup_calibration(obs_source="derived")` computes the elapsed-time → ISO-date
  map at setup time (pandas is available) and emits it into the stdlib-only
  forward wrapper as literals, so the wrapper needs no date library beyond
  `datetime`.
- The `%Y` numeric shortcut is removed or hard-restricted to a plausible year
  range; an observation that matches no simulated date is still skipped and
  reported, never silently mis-aligned.
- A regression test uses an elapsed-day axis with non-January-1 observation
  dates, mirroring the holdout shape.

**Critical 2 — solver options (plan defect).** Task 1's spike recorded Newton as
mandatory for the CSUB delay solve, but no task exposed solver configuration;
the tiny e2e avoided delay interbeds, which H201 has. The MCP-only rule leaves
the closed-book agent no remedy.

- `set_simulation` gains optional solver fields (`newton`,
  `linear_acceleration`, `outer_maximum`, `under_relaxation`, and the existing
  `complexity`), applied to the GWF `newtonoptions` and the `ModflowIms`
  package. No new tool is added; the tool count stays 74.
- An MF6-gated delay-interbed e2e test mirrors H201 (delay + no-delay interbeds,
  Newton enabled, holdout IMS settings), so the delay path is proven end to end.

**Important fixes**

- `csub:packagedata` gets a pristine snapshot (e.g.
  `<gwf>.csub_packagedata_pristine.dat`) taken on first externalisation and
  restored before each setup, matching the NPF pattern.
- CSUB per-layer snapshots are invalidated when the CSUB arrays change:
  `clear_k_base_snapshot` (or a sibling) also removes `*_csub_*_pristine.npy`,
  called from `add_csub_package`.
- The IES path uses `_read_ies_phi` (the `mean` column), not `_read_phi_csv`'s
  all-column sum, and the e2e asserts a meaningful phi rather than a non-null
  value.

**Documentation**

- `tasks.md` v0.3.0 gate sentence and `catalog.md`'s stale CSUB row are
  corrected, and spec risk 3 (the `add_boundary_package` external-SPD
  discrepancy) is recorded in the spike findings doc.
