# PRT (particle tracking) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build MODFLOW 6 PRT (particle tracking) support — a same-simulation GWF-PRT component, MIP/PRP/OC packages, one flow+PRT run, and pathline post-processing — closed-book validated against `ex-prt-mp7-p01`.

**Architecture:** PRT is a `ModflowPrt` model inside the flow model's existing `mfsim.nam`, coupled by `ModflowGwfprt`. `add_prt_model` wraps the foundation's `builder._impl_add_component_model(model, "prt")` (which mirrors the DIS/DISV grid and registers the exchange) and adds a PRT-specific IMS. MIP/PRP/OC are added by dedicated tools. The single `run_simulation` runs GWF then PRT (exchange order). `read_pathlines`/`plot_pathlines` read and plot the PRT CSV track file.

**Tech Stack:** Python 3.11+, flopy 3.10 (`ModflowPrt`, `ModflowPrtdis`, `ModflowPrtdisv`, `ModflowPrtmip`, `ModflowPrtprp`, `ModflowPrtoc`, `ModflowGwfprt`), MODFLOW 6 (6.7.0), pytest, ruff, mypy.

**Spec:** `docs/superpowers/specs/2026-09-27-v0.3.0-prt-design.md`

## Global Constraints

- Venv: `.venv\Scripts\python.exe`. Run pytest/ruff/mypy from the repo root.
- Flow-only behaviour must be byte-for-byte unchanged; the suite baseline is **816 passed**.
- New tools: `add_prt_model`, `add_prt_mip_package`, `add_prt_prp_package`, `add_prt_oc_package`, `read_pathlines`, `plot_pathlines`. `_EXPECTED_TOOL_COUNT` 83 → 89.
- `ruff check src` and `mypy src` clean on touched files.
- PRT has **no DISU class** in flopy → a DISU source grid must fail cleanly through `_mirror_grid`.
- **Spike-confirmed MF6/flopy facts (do not re-derive):**
  - A same-simulation GWF-PRT exchange needs **per-model IMS**; the GWF IMS must be listed before the PRT IMS in `mfsim.nam`. With one IMS, MF6 aborts: "The GWF model must be solved by a different solution than the PRT model."
  - flopy `ModflowPrtprp(packagedata=...)` expects **0-based `irptno`** (flopy writes +1) and 0-based `cellid`; `perioddata` is a list-of-lists of release settings, e.g. `[["first"]]`.
  - The track file must be declared **once** (put `trackcsv_filerecord` on the OC, not the PRP) or MF6 aborts with a double-open on the same file.
  - The PRT OC emits rows only with track events enabled: `track_release=True`, `track_timestep=True`, `track_terminate=True`.
  - The PRT CSV header is exactly:
    `kper,kstp,imdl,iprp,irpt,ilay,icell,izone,istatus,ireason,trelease,t,x,y,z,name`.
  - The GWF flow model must have `save_flows=True` and `save_specific_discharge=True` on NPF, and its OC must write `HEAD`+`BUDGET`.
- **Open spike finding (Task 1 resolves it):** in the spike, particles were released (`IN: PRP = n`) but never advanced (`TERMINATION = 0`, empty CSV). Root cause not yet identified. Task 1 must produce a tiny run whose CSV has ≥1 data row before any other task starts.

## Review Focus

- **Flow coupling correctness:** a PRT run must actually track particles (non-empty pathline output), not merely terminate normally; Task 1 owns the proof.
- **Grid mirroring fidelity:** the PRT DIS/DISV must match the GWF grid exactly, including origin/rotation, or the exchange maps zero velocity.
- **Per-model IMS ordering:** `add_prt_model` must register the PRT IMS after the GWF IMS in `mfsim.nam`; re-registering must not silently drop the GWF solution.
- **Track-file discovery:** `read_pathlines`/`plot_pathlines` must find the file declared in the PRT OC and give `OUTPUT_FILE_MISSING` before a run, not a crash or a stale file.
- **Flow-only regression:** every existing tool with no PRT component behaves exactly as before.

```python
def _mf6_available() -> bool:

def _build_flow_and_prt(root: Path, *, nstp: int = 10) -> Path:
    ws = root / "prtsim"
    ws.mkdir()
    sim = mf6.MFSimulation(sim_name="prt", version="mf6", sim_ws=str(ws))
    mf6.ModflowTdis(sim, nper=1, perioddata=[(float(nstp), nstp, 1.0)], time_units="DAYS")

    gwf = mf6.ModflowGwf(sim, modelname="gwf", model_nam_file="gwf.nam", save_flows=True)
    ims_gwf = mf6.ModflowIms(sim, complexity="SIMPLE", filename="gwf.ims")
    sim.register_ims_package(ims_gwf, ["gwf"])
    mf6.ModflowGwfdis(gwf, nlay=1, nrow=1, ncol=10, delr=1.0, delc=1.0,
                      top=1.0, botm=0.0, length_units="METERS")
    mf6.ModflowGwfnpf(gwf, icelltype=0, k=1.0, save_flows=True, save_specific_discharge=True)
    mf6.ModflowGwfic(gwf, strt=1.0)
    mf6.ModflowGwfchd(gwf, stress_period_data={0: [[(0, 0, 0), 1.0], [(0, 0, 9), 0.0]]})
    mf6.ModflowGwfoc(gwf, head_filerecord="gwf.hds", budget_filerecord="gwf.cbc",
                     saverecord=[("HEAD", "ALL"), ("BUDGET", "ALL")])

    prt = mf6.ModflowPrt(sim, modelname="prt", model_nam_file="prt.nam", save_flows=True)
    ims_prt = mf6.ModflowIms(sim, complexity="SIMPLE", filename="prt.ims")
    sim.register_ims_package(ims_prt, ["prt"])
    mf6.ModflowPrtdis(prt, nlay=1, nrow=1, ncol=10, delr=1.0, delc=1.0,
                      top=1.0, botm=0.0, length_units="METERS")
    mf6.ModflowPrtmip(prt, porosity=0.2, retfactor=1.0)
    mf6.ModflowPrtprp(prt, nreleasepts=1,
                      packagedata=[(0, (0, 0, 4), 4.5, 0.5, 0.5)],
                      perioddata=[["all"]])
    mf6.ModflowPrtoc(prt, trackcsv_filerecord="prt.trk.csv",
                     track_release=True, track_timestep=True, track_terminate=True)
    mf6.ModflowGwfprt(sim, exgmnamea="gwf", exgmnameb="prt")

    sim.write_simulation(silent=True)
    ok, buff = sim.run_simulation(silent=True)
    assert ok, "\n".join(buff or []) + "\n" + (ws / "mfsim.lst").read_text()[-4000:]
    return ws


@requires_mf6
def test_prt_track_csv_has_particles(tmp_path):

    assert csv.exists()
    rows = [ln for ln in csv.read_text().splitlines() if ln.strip()]
    # header + at least one particle record
    assert len(rows) >= 2, "PRT released particles but wrote no pathline rows"
```

```python
def _ensure_flow_saving_for_prt(model: str) -> None:
    """Ensure the GWF model exposes what the GWF-PRT exchange needs."""
    gwf = get_model(model, "gwf")
    npf = gwf.get_package("npf")
    if npf is not None:
        for attr, value in (("save_flows", True), ("save_specific_discharge", True)):
            try:
                setattr(npf, attr, value)
            except Exception:
                pass


def _impl_add_prt_model(model: str) -> dict:
    """Add a same-simulation PRT model with the flow grid mirrored + exchange."""
    _require_writable(model, "add_prt_model")
    key = "prt"
    if key in component_map(model):
        raise ValueError(f"Simulation '{model}' already has a '{key}' component.")

    _ensure_flow_saving_for_prt(model)
    out = _impl_add_component_model(model, key)

    # A same-simulation GWF-PRT exchange requires the PRT model to be solved by
    # its own IMS listed after the GWF model's IMS in mfsim.nam.
    sim = get_sim(model)
    ims_name = f"{out['component_model']}.ims"
    ims = mf6.ModflowIms(sim, complexity="SIMPLE", filename=ims_name)
    sim.register_ims_package(ims, [out["component_model"]])
    out["ims"] = ims_name
    out["written"] = save_sim(model, sim)
    return out
```

```python
def _impl_add_prt_mip_package(
    model: str, porosity, retfactor: float = 1.0, izone=None, save_flows: bool = False
) -> dict:
    """Add the PRT matrix-input (MIP) package: porosity and retardation."""
    _require_writable(model, "add_prt_mip_package")
    prt = get_model(model, "prt")
    pkg = prt.get_package("mip")
    if pkg is not None:
        prt.remove_package(pkg)
    kwargs: dict = {"porosity": porosity, "retfactor": retfactor}
    if izone is not None:
        kwargs["izone"] = izone
    mf6.ModflowPrtmip(prt, **kwargs)
    return {"model": model, "package": "MIP", "written": save_sim(model, prt.simulation)}
```

```python
def _impl_add_prt_prp_package(
    model: str,
    release_points: list,
    perioddata: list | None = None,
    release_times: list | None = None,
    save_flows: bool = False,
) -> dict:
    """Add the PRT particle-release (PRP) package.

    ``release_points`` is ``[(irptno, cellid, xrpt, yrpt, zrpt[, boundname])]``
    with 0-based ``irptno`` (flopy writes the 1-based MF6 value). ``perioddata``
    is the per-period release setting, e.g. ``[["first"]]``.
    """
    _require_writable(model, "add_prt_prp_package")
    prt = get_model(model, "prt")
    pkg = prt.get_package("prp")
    if pkg is not None:
        prt.remove_package(pkg)
    kwargs: dict = {
        "nreleasepts": len(release_points),
        "packagedata": release_points,
    }
    if perioddata is not None:
        kwargs["perioddata"] = perioddata
    if release_times is not None:
        kwargs["releasetimes"] = release_times
    if save_flows:
        kwargs["save_flows"] = True
    mf6.ModflowPrtprp(prt, **kwargs)
    return {
        "model": model,
        "package": "PRP",
        "file": f"{prt.name}.prp",
        "written": save_sim(model, prt.simulation),
    }
```

```python
def _impl_add_prt_oc_package(
    model: str,
    track_filerecord: str | None = None,
    trackcsv_filerecord: str | None = None,
    track_release: bool = True,
    track_timestep: bool = True,
    track_terminate: bool = True,
    track_exit: bool = False,
    budget_filerecord: str | None = None,
) -> dict:
    """Add the PRT output-control (OC) package with tracking output.

    Declare the track file here (not on the PRP) — MF6 aborts if the same file
    is declared twice.
    """
    _require_writable(model, "add_prt_oc_package")
    prt = get_model(model, "prt")
    pkg = prt.get_package("oc")
    if pkg is not None:
        prt.remove_package(pkg)
    kwargs: dict = {}
    if trackcsv_filerecord:
        kwargs["trackcsv_filerecord"] = trackcsv_filerecord
    if track_filerecord:
        kwargs["track_filerecord"] = track_filerecord
    if budget_filerecord:
        kwargs["budget_filerecord"] = budget_filerecord
    if track_release:
        kwargs["track_release"] = True
    if track_timestep:
        kwargs["track_timestep"] = True
    if track_terminate:
        kwargs["track_terminate"] = True
    if track_exit:
        kwargs["track_exit"] = True
    mf6.ModflowPrtoc(prt, **kwargs)
    return {
        "model": model,
        "package": "OC",
        "model_name": prt.name,
        "written": save_sim(model, prt.simulation),
    }
```
